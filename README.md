# Govind Unnikrishnan · Physics portfolio

Static academic portfolio for research, instrumentation, writing, and photographs. Open `index.html` locally or publish the repository as a GitHub Pages user site at `https://govindjocose006.github.io/`. No build step or framework is needed.

## Publishing

Use repository name `govindjocose006.github.io`, place these files at the repository root, and configure GitHub Pages to serve from the `main` branch root. URLs in the document and sitemap assume that address. If you use a different host, replace the canonical URL, structured-data URL, robots sitemap address, and sitemap.xml location.

## Content

Both MS thesis PDFs and the CV are in `assets/`. The manuscript is labelled unpublished and is intentionally not linked. The external reference photographs are credited by source in the instrument section; the other photographs were provided by Govind. The representative external instrument photographs should not be mistaken for pictures of the specific instruments at IISER or UGC-DAE.
